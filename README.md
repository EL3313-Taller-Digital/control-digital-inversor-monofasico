
# Control Digital de un Inversor Monofásico

EL3313 — Taller de Diseño Digital  
II Semestre 2026

## Descripción

Diseño e implementación de un sistema embebido en FPGA basado en MicroBlaze V para el control de corriente de un inversor monofásico.

El sistema integra un controlador proporcional-resonante (PR) discreto, adquisición de corriente mediante XADC, generación de PWM unipolar con tiempo muerto configurable y comunicación UART.

El desarrollo se realiza en coordinación con el curso EL4201 — Procesamiento Electrónico de Potencia.

## Tecnologías

- Vivado y Vitis
- MicroBlaze V (RISC-V)
- SystemVerilog
- AXI4-Lite
- C embebido
- FPGA Artix-7
- GitHub
