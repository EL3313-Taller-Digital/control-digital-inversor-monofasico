# Diseño de hardware en Vivado

Esta carpeta contiene los archivos relacionados con el diseño e implementación del sistema digital de control de corriente para un inversor monofásico sobre FPGA Basys 3.

El sistema integra un procesador MicroBlaze V, adquisición analógica mediante XADC, generación PWM unipolar y comunicación con los periféricos mediante AXI4-Lite.

Los archivos de hardware incluyen los módulos RTL, las restricciones de pines, el diseño de bloques y los componentes necesarios para sintetizar e implementar el sistema utilizando Vivado 2026.1.
